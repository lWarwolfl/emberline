EMBERLINE — WINDOWS DESKTOP

Build: npm ci, then npm run dist:desktop.
Install release/EMBERLINE-Setup-7.1.0.exe and launch EMBERLINE.
Players need no browser, Node installation or terminal.
Unsigned installer: Windows may display a publisher warning.

LAN hosting starts automatically with the app on port 4174.
Choose PARTY / LAN, then HOST LAN ROOM.
Share the displayed LAN address and room code.
Other desktop players enter that address and code before JOIN LAN.
Browser players can open the shared address directly.
Keep the host app open and allow private-network firewall access if prompted.

Desktop saves are separate from browser saves. Solo works offline.
Direct internet invites still depend on compatible networks.
Web/PWA and Play.cmd playback remain supported.
Read README.md for controls, limitations and packaging.
