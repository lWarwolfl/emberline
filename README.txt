EMBERLINE v5 — CAPPED UPGRADES
==============================
Play.cmd launches the offline game. L opens the shop and upgrades.

Dash / Jump height / Attack damage: max level 5.
Each track costs 100, 200, 300, 400, 500 coins for levels 1–5.
Triple Jump: one-time 5,000-coin unlock, max level 1.
All abilities start basic. Upgrades apply next run and save permanently.

Skins: 500 / 900 / 1,500. Guns: 1,200 / 2,400 coins.
Previously owned gear and coin balances are retained.
Pickup rewards: Easy 1 / Courier 2 / Overdrive 3 / Custom 0.

Shop upgrades show level, next improvement and price. Use Details for stats.
Space / Up: jump (third jump after unlock). Shift: dash. X / J: attack.
P: pause. F: fullscreen/windowed. M: sound. Touch controls included.

Mobile uses a full-height seamless shell with safe-area padding and large thumb
controls. On HTTPS the game installs as an app and runs offline after first load.

Read README.md and docs/DEVELOPMENT.md for source and balance settings.
